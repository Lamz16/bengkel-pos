# Katalog Alur Bisnis BengkelPro POS

Dokumen ini dibuat dari pembacaan statis UI, API, route, controller/service/repository, type, Prisma schema/migrasi, README, dan `.env.example`. File `.env` tidak dibaca.

## Peta menu dan akses UI
- `dashboard` — **Dashboard**: Owner
- `pos` — **Transaksi**: Owner, Admin, Kasir, Staf
- `receivables` — **Piutang**: Owner
- `queue` — **Antrean Servis**: Owner, Admin, Kasir, Staf
- `distributor_tempo` — **Nota Tempo**: Owner
- `mechanics` — **Mekanik & Gaji**: Owner
- `customers` — **Pelanggan**: Owner
- `inventory` — **Stok Barang**: Owner, Admin, Kasir, Staf
- `suppliers` — **Pemasok**: Owner
- `expenses` — **Pengeluaran**: Owner
- `reports` — **Laporan**: Owner
- `completed_transactions_report` — **Laporan Transaksi Selesai**: Owner
- `logs` — **Log Sistem**: Owner
- `staff` — **Pengguna**: Owner
- `settings` — **Pengaturan**: Owner
